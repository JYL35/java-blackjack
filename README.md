# 자바 블랙잭

## 🚀 기능 목록

### 1. 카드 (Card)
- [x] 카드 숫자(CardNumber)와 문양(CardPattern)의 조합으로 개별 카드를 관리한다.
- [x] 카드의 점수를 조회할 수 있다.
- [x] **[엣지 케이스]** 동일한 숫자와 문양을 가진 카드는 서로 동등한 객체로 취급한다(equals/hashCode 구현).

### 2. 카드 숫자 (CardNumber)
- [x] 각 카드가 가진 고유 점수를 정의한다.
    - ACE: 1점
    - 2 ~ 9: 각 숫자만큼의 점수
    - 10, JACK, QUEEN, KING: 10점

### 3. 카드 문양 (CardPattern)
- [x] 4가지 문양(스페이드, 하트, 다이아몬드, 클로버)을 관리한다.

### 4. 카드 덱 (Deck)
- [x] 52장의 모든 카드 조합을 생성하고 초기화한다.
- [x] 생성 시 카드를 무작위로 섞는다(Collections.shuffle).
- [x] 덱에서 카드를 한 장씩 분배(pop)한다.
- [x] **[예외 처리]** 덱에 더 이상 남아있는 카드가 없을 때 분배를 시도하면 `IllegalStateException`이 발생한다.

### 5. 플레이어 (Player)
- [x] 이름을 가지며, 덱에서 분배받은 카드를 소지한다.
- [x] 현재 소지한 카드들의 총 점수를 합산하여 계산한다.
- [x] **[엣지 케이스]** 현재 소지한 카드를 외부에서 직접 수정할 수 없도록 방어적 복사본(`List.copyOf`)을 제공한다.
